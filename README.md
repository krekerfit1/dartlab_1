## Запуск проекта
Чтобы склонировать репозиторий и запустить проект локально, следует выполнить следующие команды в терминале:

 Клонировать репозиторий:
   ```bash
   git clone https://github.com/krekerfit1/dartlab_1.git
```
Перейти в папку проекта:
   ```bash
cd lab1_dart
```
Установить зависимости:
```bash

dart pub get
```
Запустить приложение:
   ```bash
dart run
```

**Ответы на контрольные вопросы**
1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?
   - В Dart типы переменных проверяются строго на этапе компиляции. В Python типы определяются динамически (рантайме).
   - преимущество: Компилятор Dart заранее ловит ошибоки (например попытку передать строку в числовую переменную), что повышает надежность кода и избавляет от неожиданных     падений приложения во время работы пользователя.
2. Что означает String? Чем отличается от String?
   - String — это обычная строка которая не может содержать значение null. Попытка присвоить ей null вызовет ошибку компиляции.
   - String? — это nullable-тип. Он разрешает переменной принимать значение null, что позволяет  обрабатывать отсутствие данных с помощью механизмов Null.
3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?
   -В Python неизменяемость переменных — это лишь соглашение между разработчиками
   -В Dart ключевое слово final (или const) контролируется на уровне компилятора и среды выполнения. Если попытаться изменить значение final-переменной после её                инициализации, программа просто не скомпилируется.
4.Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.
   -Позиционный параметр передается строго по своему порядку в объявлении функции.
   -Именованный параметр (заключается в фигурные скобки {}) передается по имени аргумента, порядок передачи при этом не важен. Флаг required делает такой параметр              обязательным для заполнения.
